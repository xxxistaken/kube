# AGENTS.md — 已实施 Agent Notes

这些 Agent Note 描述已交付的决策。遵循[工作区根说明](../../../AGENTS.md)与 [Agent Note 格式](../README.md#文件格式)。

## 让已实施的 Agent Note 与实际交付保持同步

在同一个变更中同步更新路径、符号、默认值与机制。就地改写过时的事实；不要追加变更历史。

当一份已交付的 note 不太可能再指导未来工作时，按 [Agent Note 规则](../README.md#归档与删除)归档，而不是继续维护。

### 这不是改写*决策*的许可

就地更新事实性落地。推翻决策或其理由需要新 Agent Note 并交叉链接；被完全取代的旧 note 只能按 [Agent Note 规则](../README.md#何时需要写一份) 中的合并规则删除。
