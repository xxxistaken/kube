# AGENTS.md — Agents Notes

Agent Notes 本质上是 agent 书写的 RFC：持久的提案与决策记录，保存理由、备选方案、后果与必要的验证。遵循[工作区根说明](../../AGENTS.md)与 [Agent Note 规则](README.md)。

**每份新 Agent Note 都要触发一次取代检查。** 在活跃目录树中搜索覆盖同一决策或机制的旧 note，判断全部或部分取代关系：全部取代的已实施记录按[归档与删除](README.md#归档与删除)在同一变更中归档其完整文件；部分取代的保持活跃并交叉链接。

[`archived/`](archived/AGENTS.md) 下的文件是冻结的历史快照：不得编辑，也不得视为当前行为的权威依据。
