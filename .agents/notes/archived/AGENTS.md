# AGENTS.md — 已归档 Agent Notes

归档目录下的文件是冻结的历史快照，不是当前行为的权威依据。不得编辑、重新格式化、翻译、修复、删除或移动已封存的文件；新的决策与事实使用活跃 Agent Note 或当前文档。

归档变更只允许：移动文件、在 `Status: implemented` 行下方插入相同的 `Archived: YYYY-MM-DD` 行、修复或删除入站链接。不要检查、验证或修复从归档 note 发出的链接。本工作区无自动化校验（deepseek-harness 的 `verify-archived-agent-notes` 在此不适用），冻结靠 review 纪律保证。
